# ITMO DevOps лабораторные работы
## Содержание
### В данном семестре по предмету “Осноы DevOps методологии“ мною было выполнено пять работ по основным концепциям DevOps, в работе отдельное внимание уделяется современным технологиям, безопасности продакшн уровня (например, hashicorp vault) и полноте цикла разработки.
## Описание работ
1. Docker и Docker compose
2. Kubernetes & Helm
3. Nginx & Site Reliability
4. CI/CD (GitHub actions)
5. Мониторинг (Grafana)
## Вывод
В данных работах я показал навыки контейнеризации, оркестризации, развертыванию сервисов и сайтов, циклу разработки сервиса и мониторингу
